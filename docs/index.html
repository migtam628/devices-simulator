QUESTIONS ANSWERED

Frequently asked questions.

Answers for developers, QA teams and companies evaluating Devices Simulator.

Is it a real printer, scanner or physical device?

No. This is a simulator for software testing. Certain printers can be registered as experimental OS queues, but that does not create physical hardware or a native scanner driver.

Can I use it for production fulfillment?

No. A JPG capture or accepted OS print job does not prove a physical label was printed, and the simulator must not mark orders shipped.

Does the barcode simulator install a true HID scanner?

No. On macOS it sends keyboard events with Accessibility approval. Actual virtual HID devices require separate platform-specific implementations.

Can my company use or redistribute the source commercially?

A software license has not yet been published. Contact the maintainer about licensing and support before company-wide or commercial use.
